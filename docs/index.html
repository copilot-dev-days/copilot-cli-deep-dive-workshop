Operating Modes

Interactive chat, interactive-with-prompt, slash commands, programmatic mode, and delegate — master every way to use Copilot CLI.

Custom Instructions

AGENTS.md, copilot-instructions.md, and path-specific instructions to guide Copilot's behavior and coding style; inspect loaded sources with /instructions.

🔌

MCP Servers & Tools

Connect to GitHub MCP, configure local/remote servers, and control access with tool, path, and URL permissions, permission modes, and command sandboxing.

Build custom agents, use built-in research and review agents, create reusable skills alongside the built-in ones, and leverage the plugin ecosystem.

Hooks & Automation

⚙️

Configuration

User settings in settings.json, managed policy, opt-in session limits and AI credits, context management, IDE integration, accessibility, and team standardization.
